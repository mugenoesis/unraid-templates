# Unraid templates

Unraid [Community Apps](https://ca.unraid.net/) templates for apps by mugenoesis.

| App | Template | Image |
|---|---|---|
| **Trident**, a self-hosted slicer with a web UI | [`templates/trident.xml`](templates/trident.xml) | `mugenoesis/trident` on Docker Hub |
| **Holecraft**, browser-based 3D modelling for makers, with resin tools that work with Trident | [`templates/holecraft.xml`](templates/holecraft.xml) | `mugenoesis/holecraft` on Docker Hub |

Trident's source and issue tracker are at https://github.com/mugenoesis/Trident, Holecraft's at https://github.com/mugenoesis/holecraft.
